Featured Engineering Project

CODESYS Conveyor Control System with Modbus TCP VFD Simulation

I'm developing a PLC-based conveyor control system to strengthen my understanding of industrial automation, machine control logic, and communication between control components.

The project uses CODESYS and Structured Text. It includes conveyor control logic, reusable function blocks, HMI-related variables, fault management, jam monitoring, product counting, and a software-based VFD simulator.

Key Engineering Components

  • PLC programming: Organizing control logic into programs, global variables, and reusable function blocks.
  • Conveyor control: Developing machine-ready logic, operating conditions, product counting, and jam monitoring.
  • Fault management: Implementing simulated fault detection, status handling, and reset behavior.
  • VFD simulation: Modeling run commands, speed setpoints, speed ramping, and simulated drive feedback.
  • Modbus TCP: Working on client/server communication, register mapping, run commands, speed feedback, and status-word processing.

What I'm Learning

This project is helping me connect programming concepts with industrial control principles, including machine states, interlocks, data types, communication registers, fault conditions, and systematic troubleshooting.

Project status: In development. This project currently focuses on software-based control and VFD simulation; it should not be interpreted as a commissioned physical conveyor system.
